:: About This Page ::

This page is a demo mock-up site built in the classic late-90's personal homepage style — the kind of page you'd have found hosted on a free web host back in the day, complete with tiled starfield backgrounds, chunky beveled buttons, scrolling marquees, and a healthy disrespect for whitespace.

Why It Looks Like This

Back before CSS frameworks and responsive grids, web pages were built with HTML tables, animated GIFs, and a serious love of neon color combinations. This mock-up borrows all of that: a starry tiled background, beveled nav buttons, a rainbow divider bar, and of course the obligatory blinking "Under Construction" stripe.

Tech Stack

  • Plain HTML — no build tools, no bundlers
  • One shared style.css file
  • Hand-generated pixel-style images (no stock photos)
  • CSS animations standing in for the old animated GIFs

Use It However You Like

Feel free to use this as a starting point for your own retro project, a Halloween joke site, a band page, or just to remind yourself what the web used to feel like before it got so serious.
